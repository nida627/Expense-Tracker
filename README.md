# Expense Tracker

## Overview

Expense Tracker is a Python-based console application that helps users record and manage their daily expenses. The application stores expense data in a file, allowing users to access their records even after restarting the program.

This project was developed to learn File Handling and Data Persistence in Python.

---

## Features

- Add new expenses
- View all saved expenses
- Generate spending summary
- Store expenses permanently in a file
- Exception handling for invalid inputs
- Menu-driven interface

---

## Technologies Used

- Python 3.x
- Visual Studio Code

## How to Run

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Open the project folder:

```bash
cd Expense-Tracker
```

3. Run the program:

```bash
python expense_tracker.py
```
